# 边缘 AI 部署 · 学习与项目记录

> 电子信息工程 → 边缘 AI / 嵌入式部署
> 目标：走通「传感器采信号 → PC 上训练 → 量化压缩 → MCU 上实时推理」这一条链。

## 我在做什么

用一年时间做一个完整项目：**音频/振动信号分类模型，量化后部署到单片机上实时运行。**

不用「准确率 95%」这种话汇报，用数字：

- 模型从 `__ MB` 压到 `__ KB`
- 延迟从 `__ ms` 降到 `__ ms`
- 精度掉了 `__` 个百分点（FP32 → INT8）
